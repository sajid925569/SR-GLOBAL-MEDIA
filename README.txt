SR GLOBAL MEDIA — static starter website
Files: index.html, style.css, app.js.
This is a front-end design demo. It does not yet have a secure admin login, database, or public article publishing system.
To publish for free from a phone, one option is GitHub Pages:
1) Create/sign in to GitHub.
2) Create a public repository (example: sr-global-media).
3) Upload these three files to the repository root.
4) Open repository Settings > Pages and choose Deploy from a branch, branch main, folder /(root), then Save.
5) Wait for the published URL shown on the Pages settings screen.
GitHub mobile UI may differ. Keep this prototype free of passwords/secrets. A real admin/news publishing system needs a backend/database and authentication.
